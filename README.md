# 👩🍳 GreenChef AI

An AI-powered recipe generator that creates personalized
restaurant-style recipes from ingredients you already have.

## ✨ Features
- AI recipe generation using OpenAI GPT-3.5
- Filter by diet type, cuisine & meal type
- Smart ingredient validation
- Step-by-step cooking modal
- Save favourite recipes
- List & grid view toggle
- Fully responsive design

## 🛠️ Tech Stack
React · OpenAI API · Node.js · Axios · CSS3 · Vercel

## ⚙️ Local Setup
1. Clone the repo
   git clone https://github.com/Aailaimran/greenchef-ai.git
   cd greenchef-ai

2. Install dependencies
   npm install

3. Create .env file in root
   OPENAI_API_KEY=your_openai_key_here

4. Start development server
   npm start

## 🚀 Deployment
Deployed on Vercel with serverless API functions.
Environment variable OPENAI_API_KEY must be set in Vercel dashboard.
