# GreenChef AI — Recipe Generator

An AI-powered recipe generator that creates personalized
recipes based on ingredients you already have at home.

## Features
- AI recipe generation using OpenAI GPT-3.5
- Filter by diet, cuisine & meal type
- Ingredient validation (blocks non-food inputs)
- Step-by-step cooking modal
- Save favourite recipes
- Responsive design

##  Tech Stack
React · OpenAI API · Node.js · Axios · CSS3

## Setup
1. Clone the repo
   git clone https://github.com/Aailaimran/greenchef-ai.git
2. Install dependencies
   npm install
3. Add your OpenAI API key to .env
   REACT_APP_OPENAI_API_KEY=your_key_here
4. Start the app
   npm start
